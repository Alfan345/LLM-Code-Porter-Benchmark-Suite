# AI Transpiler and Performance Benchmark Dashboard
Translate Python code to C++/Rust using LLMs with a Self-Correction Loop, and benchmark the execution speed instantly on Hugging Face Spaces.

### System Configuration
* **Backend Compilers:** GCC/G++ (C++17) and Rustc (Standard Library only) via system `apt` packages.
* **Architecture:** Gradio SDK execution environment.
